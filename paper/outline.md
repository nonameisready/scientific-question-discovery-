# Paper Outline (Draft)

## Title (tentative)

Scientific Question Discovery: Toward Question-Asking as a Core Capability of AGI

## Thesis

One of the key capabilities on the path to AGI is not answering questions but discovering scientific questions worth investigating. This paper proposes a formal framework for scientific question discovery, an evaluation benchmark, and experimental validation.

## Section Structure

1. **Introduction** — Motivation: why question-asking is a core capability of AGI
2. **Related Work** — Automated scientific discovery, open-ended learning, curiosity-driven agents, LLMs for science
3. **Framework** — Formalizing scientific question discovery: question space, novelty, feasibility, value function
4. **Benchmark** — Task design, scoring rubrics, baseline methods
5. **Experiments** — Main experiments, ablation studies, case analyses
6. **Discussion** — Limitations, implications for AGI research
7. **Conclusion**

## Open Problems

- [ ] How do we quantify the "value" of a scientific question?
